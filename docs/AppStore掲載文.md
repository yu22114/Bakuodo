## 説明文（4,000文字まで）

```
爆踊（バクオドリ）は、ダンサーが集まり・つながるためのコミュニティアプリです。
「今日どこで踊れる？」「一緒に練習できる人いない？」を、アプリひとつで解決します。

■ CYPHER（サイファー）
最寄り駅と日時を入れるだけで、すぐにサイファーを開催できます。
近くで開かれるサイファーを見つけて、ワンタップで参加。
フォロワー限定・参加承認制にも対応しています。

■ LESSON（プライベートレッスン）／ EVENT（イベント）
レッスンやイベントを告知して、参加申込を受け付けられます。
料金・対象レベル・定員の設定、画像の添付、JUDGE・DJ・MCの紹介もできます。
終わったイベントは、当日の写真を「振り返り」として残せます。

■ NUMBER（振付作品の出演者募集）
発表会やイベントに向けた振付作品の出演者を募集できます。
想定練習期間・募集人数・募集期限を決めて投稿するだけ。

■ マイコミュニティ
チーム・団体のための掲示板です。
練習日程の出欠（○／△／×）や、曲のパートごとの担当振付をまとめて管理できます。

■ SPOTS（聖地スポット）
ダンサーが自然と集まる有名な練習場所に、今だれがいるかをチェック。
「ここにいる！」ボタンでチェックインできます。

■ そのほか
・エリア・日程・ジャンルで絞り込み検索
・気になる投稿をブックマーク
・参加者どうしでコメント
・Instagramストーリーズ用の告知画像を書き出し

ストリートダンス、ブレイキン、ヒップホップ、ハウス、ポッピン、ロッキンなど、ジャンルを問わず使えます。
```

収集するデータ（どれも「ユーザーに紐づく」「トラッキングには使わない」「目的：アプリの機能」）

|---|---|
